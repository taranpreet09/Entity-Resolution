## 1. Overview & File Inventory

The dataset originates from the Kaggle **Foursquare Location Matching** competition. The preprocessed tabular split files `train0.csv` and `train1.csv` contain single-table deduplication records of points of interest (POIs) worldwide.

| File Name | Row Count | File Size | Role / Usage |
|---|---|---|---|
| `train0.csv` | 569,406 | ~115.8 MB | Labeled POI records (Part 1) |
| `train1.csv` | 569,406 | ~115.7 MB | Labeled POI records (Part 2) |
| **Combined** | **1,138,812** | **~231.5 MB** | Full Labeled Record Store |

> [!IMPORTANT]
> **Evaluation Exclusion Guards:**
> - `test.csv` contains unlabelled competition queries with no `point_of_interest` target column. It **MUST NOT** be used for model evaluation.
> - `pairs.csv` / `haversine_train*.csv` contains pre-blocked candidate pairs generated by a heuristic pipeline. It **MUST NOT** be used for retrieval evaluation as it represents a filtered candidate subset rather than full ground truth.
